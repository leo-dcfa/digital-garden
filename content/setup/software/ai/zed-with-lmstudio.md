1. Download LM Studio
2. Click on `Explore` and select a model you want to experiment with. I chose `qwen 3.6-35B-3B` for my first experiment.
3. Go to CLI and start LM Studio server with `lms server start`
4. Now in Zed open the agent pannel and click on `+`
5. Scroll down to LM Studio and click on `Connect`
6. Start a new thread and choose the model you want to try out
7. Vibe away
